# CampusCafé

Projet Python de caisse pour la cafétéria du campus.

Done by Amine Boucif

## Variante choisie

- Axe A : **A1 - Tarif solidaire**
  - étudiant : remise de 10 %
  - alternant : remise de 5 %
  - personnel : aucune remise
  - visiteur : 0,50 € de frais de service
- Axe B : **B1 - Points**
  - 1 point par euro entier payé
  - à partir de 30 points, la commande suivante reçoit 2,00 € de remise
  - les 30 points utilisés sont ensuite retirés

## Organisation du projet

- `Produit.py` : représente un produit de la carte et son stock.
- `Client.py` : représente un client, son profil, son solde et sa fidélité.
- `Commande.py` : représente une commande et ses lignes.
- `Cafeteria.py` : contient la carte, les clients, les commandes et le scénario.
- `Profile.py` : contient les profils des clients.
- `Paiment.py` : contient les moyens de paiement.

## Produit

Un plat est disponible seulement entre `11:30` inclus et `14:00` exclue.
Les heures sont écrites au format `HH:MM`.

Les codes des produits utilisent la lettre `O`, par exemple `BO1`, `VO1`,
`PO1` et `DO1`.

## Lancement

Depuis le dossier du projet :

```bash
python Cafeteria.py
```

Le rapport est aussi enregistré dans `sortie_scenario.txt`.

Pour lancer les tests :

```bash
python test.py
```

## Objectif

Le programme doit accepter ou refuser les commandes sans modifier le stock,
le solde ou la fidélité lorsqu'une vérification échoue.
